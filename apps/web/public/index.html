Apple Music,
linked to Last.fm.

lfm is a tiny local daemon that watches what you’re playing in Music, scrobbles it correctly to Last.fm, and optionally mirrors it on Discord Rich Presence.

Get started View source
  • No audio sniffing
  • Official Last.fm API
  • Single static binary

Built for people who actually listen

Correct scrobble rules, pause-aware timing, and a background LaunchAgent when you want set-and-forget.

True scrobble rules

Duration over 30s, then 50% played or 4 minutes — the same thresholds Last.fm expects.

Pause-aware

Wall-clock accumulation only while Music is playing. Pause, resume, no double scrobbles.

Discord presence

Optional Rich Presence shows track, artist, and album art while you listen — no extra apps.

LaunchAgent

lfm install starts at login. Logs live under ~/Library/Logs/lfm.

Discord Rich Presence

Create a Discord application, drop in the client ID, and lfm will update your status when a track plays or pauses. Album art is resolved automatically via Last.fm / iTunes. Works alongside Last.fm scrobbling in the same process (including LaunchAgent). 

discord:
  enabled: true
  client_id: "YOUR_DISCORD_APP_ID"
  large_image: "lfm"   # fallback portal asset if cover art fails
  large_text: "lfm"

Install

  1. 1

    Clone & build

    git clone https://github.com/watashiwaaniket/lfm.git
cd lfm/apps/cli
go build -o lfm .
mkdir -p ~/bin && cp lfm ~/bin/lfm
  2. 2

    Configure Last.fm

    Create ~/.config/lfm/config.yaml with your API key & secret, then run lfm auth.

  3. 3

    Run or install

    lfm run          # foreground
lfm install      # LaunchAgent background
